**TL;DR** While preparing for the SAFe Product Owner/Product Manager (POPM) exam, I built my own MCQ practice platform with AI, so that the way I studied matched the way the exam tests. I treated my own exam prep as a product problem: one user, one clear job, one deadline.

| | |
| --- | --- |
| **My role** | Product Manager and builder: scoping, content structure, build with AI tools |
| **Type** | Self-initiated AI build, solo |
| **Focus** | SAFe POPM only, done deeply, rather than a general quiz tool |
| **Study material** | AI-Empowered SAFe 26.5 workbook |

## Context and user problem

The POPM exam is a multiple-choice assessment. Reading the workbook builds understanding, but it does not tell you whether you can pick the right answer under exam conditions. I was the user: I needed a way to test myself repeatedly and see where I was weak.

## Goal

Turn passive reading into active practice, built around one exam and nothing else.

## Decision and rationale

I chose scope over reach: the platform covers **POPM only, and covers it deeply**, instead of trying to serve several certifications. One exam, one workbook as the source material, one user with a real deadline. Building it also gave me a portfolio piece that shows product thinking applied to a problem I actually had.

## What I shipped

A POPM practice quiz platform for MCQ assessment preparation, built with AI tools.

## What I would do differently

I would define the success metric before building, for example mock-exam score trend or time to reach a target score, so the platform could show whether it worked instead of only being used.
